# Changelog — Nexus skill set

## 1.0 — 2026-08-06

Initial release.

`nexus-customer-prompt.md` (entry point) routes into `nexus-skill.md`, which
determines the site/product/task and then loads the relevant skill file(s):
product, post, category, categories, badges, sidebar, header, or preferences.
All section and block settings have been verified against the theme source.
